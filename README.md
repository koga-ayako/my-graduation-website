## サービス概要

とんこつラーメンに特化した検索サービスです。  
地域やスープの濃さ、評価などの条件から店舗を検索できるほか、  
地図検索や現在地検索にも対応しています。  
ユーザー登録を行うことで、口コミ投稿・星評価・お気に入り登録  
などの機能を利用できます。

## 開発背景

私は福岡県出身で、とんこつラーメンが好きです。  
福岡には多くのとんこつラーメン店がありますが、県外へ引っ越した友人から  
「美味しいとんこつラーメンのお店を探すのが難しい」という話を聞きました。  
既存のグルメサイトでは様々なジャンルのお店が表示されるため、    
とんこつラーメンだけを探したい場合でも検索に時間がかかります。  
そこで、「とんこつラーメン好きが、自分好みのお店を簡単に見つけられるサービス」  
を作りたいと考え、本サービスを開発しました。


## ターゲットユーザー

- とんこつラーメンが好きな方

- 現在地周辺のラーメン店を探したい方
- 新しいラーメン店を開拓したい方

## 主な機能

### 👤 認証機能

- ユーザー登録・ログイン・ログアウト
- パスワードリセット機能
- Sorceryを使用したシンプルで安全な認証

### 🔍 店舗検索機能

- **店名検索**: お店の名前から直接検索
- **地図検索**: Google Maps上で視覚的に検索
- **複数条件検索**: 地域・スープの濃さ・評価を組み合わせて検索

### 💬 コミュニティ機能

- **お気に入り登録**: 気になるお店をブックマーク
- **星評価**: 5段階評価でお店を評価
- **口コミ投稿**: 写真付きでレビューを共有
## サービスの特徴

### 🍜 とんこつラーメン専門検索

とんこつラーメンに特化することで、目的のお店を効率よく探せるようにしています。

### 🗺️ 地図検索・現在地検索

Google Maps APIを利用し、現在地や指定した場所周辺の店舗を地図上で検索できます。  
土地勘のない観光客でも安心して利用できます。

### 🔍 条件検索

以下の条件を組み合わせて検索できます。

- 地域（福岡、大阪、東京の各エリア）
- スープの濃さ（こってり・普通・あっさり）
- 評価（星評価による絞り込み）

## 使用技術・選定理由

| カテゴリ | 使用技術 | 選定理由 |
| --- | --- | --- |
| バックエンド | Ruby on Rails | MVCアーキテクチャを採用しており、保守性が高く、CRUD機能や認証機能を効率的に実装できるため。 |
| データベース | PostgreSQL | Railsとの相性が良く、ユーザー・店舗・口コミなどの関連データを安定して管理できるため。 |
| フロントエンド | HTML / CSS / JavaScript | 地図操作や現在地取得、検索結果表示など、ユーザー操作に応じた動的な画面を実装するため。 |
| UI | Bootstrap | レスポンシブ対応やモーダルなどを効率よく実装するため。 |
| 地図表示 | Google Maps JavaScript API | 店舗を地図上に表示し、視覚的に店舗を探せるサービスを実現するため。 |
| 認証 | Sorcery | シンプルな構成でユーザー認証機能を実装できるため。 |
| 検索 | Ransack | 地域・スープ濃度・評価などの複数条件検索を効率よく実装するため。 |
| 画像投稿 | CarrierWave | 口コミや掲示板へ画像を投稿できるようにするため。 |
| ページネーション | Kaminari | 店舗一覧や投稿一覧をページ分割し、見やすさを向上させるため。 |
| デプロイ | Render | GitHubと連携し、Railsアプリケーションを公開・運用するため。 |
| バージョン管理 | Git / GitHub | ソースコードの変更履歴を管理し、安全に開発を進めるため。 |

## 工夫したポイント

### ① 地図検索

Google Maps API・Places APIを利用し、  
現在地周辺の店舗を探せるようにしました。  
土地勘のない観光客でも利用しやすいよう意識しました。

### ② 複数条件検索

Ransackを利用し、地域、スープの濃さ、評価    
など複数条件を組み合わせて検索できます。  
ユーザー好みのお店を探しやすいよう意識しました。

### ③ コミュニティ機能

レビュー・評価・お気に入り登録を実装し、  
ユーザー同士で情報共有できるようにしました。  
写真付きレビューにも対応しています。
