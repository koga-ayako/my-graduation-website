## サービス概要

とんこつラーメンに特化した検索サービスです。  
地域やスープの濃さ、評価などの条件から店舗を検索できるほか、  
地図検索や現在地検索にも対応しています。  
ユーザー登録を行うことで、口コミ投稿・星評価・お気に入り登録  
などの機能を利用できます。

## 開発背景

私は福岡県出身で、とんこつラーメンが大好きです。  
福岡には多くのとんこつラーメン店がありますが、県外へ引っ越した友人から    
「美味しいとんこつラーメンのお店を探すのが難しい」という話を聞きました。  
既存のグルメサイトでは様々なジャンルのお店が表示されるため、    
とんこつラーメンだけを探したい場合でも検索に時間がかかるという課題がありました。  
また、観光客の方が土地勘のない場所で店舗を探す際に困っている様子も見てきました。  
そこで、以下の課題を解決するサービスを作りたいと考えました。

✅ とんこつラーメン専門の検索サービス  
✅ 地図上で視覚的に店舗を探せる機能  
✅ 自分好みの条件で絞り込める検索機能  

「とんこつラーメン好きが、自分好みのお店を簡単に見つけられるサービス」を目指し、本サービスを開発しました。

## ターゲットユーザー

- とんこつラーメンが好きな方
- 福岡へ旅行・出張に来た方
- 現在地周辺のラーメン店を探したい方
- 新しいラーメン店を開拓したい方

## 主な機能

### 👤 認証機能

- ユーザー登録・ログイン・ログアウト
- Sorceryを使用したシンプルで安全な認証

### 🔍 店舗検索機能

- **店名検索**: お店の名前から直接検索
- **地図検索**: Google Maps上で視覚的に検索
- **複数条件検索**: 地域・スープの濃さ・評価を組み合わせて検索

### 💬 コミュニティ機能

- **お気に入り登録**: 気になるお店をブックマーク
- **星評価**: 5段階評価でお店を評価
- **口コミ投稿**: 写真付きでレビューを共有
## サービスの特徴

### 🍜 とんこつラーメン専門検索

とんこつラーメンに特化することで、目的のお店を効率よく探せるようにしています。

### 🗺️ 地図検索・現在地検索

Google Maps APIを利用し、現在地や指定した場所周辺の店舗を地図上で検索できます。  
土地勘のない観光客でも安心して利用できます。

### 🔍 条件検索

以下の条件を組み合わせて検索できます。

- 地域（福岡、大阪、東京の各エリア）
- スープの濃さ（こってり・普通・あっさり）
- 評価（星評価による絞り込み）

## 使用技術・選定理由

### **バックエンド**

| 技術 | 選定理由 |
| --- | --- |
| Ruby on Rails | MVCアーキテクチャを採用しており、保守性が高く、CRUD機能や認証機能を効率的に実装できるため。特に、店舗・口コミ・ユーザー管理など、複数のモデルを扱う本サービスにおいて、開発スピードと保守性を両立できる。 |
| PostgreSQL | Railsとの相性が良く、リレーショナルデータベースとして信頼性が高いため。ユーザー・店舗・口コミなどの関連データを安定して管理でき、将来的な拡張性（全文検索やGIS機能）も考慮してPostgreSQLを採用。 |
| Sorcery | Deviseと比較し、シンプルな構成で認証機能を実装できるため。カスタマイズの自由度が高く、本サービスで必要な「ユーザー登録・ログイン・パスワードリセット」などの基本機能を効率的に実装できる。 |

### **フロントエンド**

| 技術 | 選定理由 |
| --- | --- |
| HTML / CSS / JavaScript | Webアプリケーションの基本技術として使用。地図操作や現在地取得、検索結果表示など、ユーザー操作に応じた動的な画面を実装するため。 |
| Bootstrap | レスポンシブ対応やモーダルなどを効率よく実装するため。カスタマイズ性が高く、スマートフォンでの利用を想定したUI設計に適している。 |

### **外部API・ライブラリ**

| 技術 | 選定理由 |
| --- | --- |
| Google Maps JavaScript API | 店舗を地図上に表示し、視覚的に店舗を探せるサービスを実現するため。マーカーのクラスタリングや現在地取得機能など、豊富な機能を活用し、ユーザー体験を向上させる。Google Maps APIは、日本国内の地図データの精度が高く、店舗検索サービスに最適。 |
| Ransack | 複数条件検索を簡潔に実装できるため。ActiveRecordと統合されており、SQLを直接書かずに複雑な検索条件を実装できる。本サービスでは、地域・スープ濃度・評価などの条件を組み合わせた検索が必要であり、Ransackを使うことで効率的に実装できる。 |
| CarrierWave | 画像アップロード機能を簡単に実装できるため。Active Storageと比較し、クラウドストレージ（AWS S3など）への移行が容易で、将来的な拡張性を考慮して採用。また、画像のリサイズやバリデーション機能も充実している。 |
| Kaminari | ページネーション機能を簡単に実装できるため。カスタマイズ性が高く、Bootstrapとの統合もスムーズ。本サービスでは、店舗一覧や口コミ一覧を見やすく表示するために、ページネーションが必須であり、Kaminariを使うことで効率的に実装できる。 |

## 工夫したポイント

### ① 地図検索

Google Maps JavaScript API・Places APIを利用し、  
現在地周辺の店舗を探せるようにしました。

**技術的な工夫:**
- Geolocation APIで現在地を取得
- 店舗データをマーカーで地図上に表示
- マーカークリックで店舗詳細をモーダル表示
- 土地勘のない観光客でも利用しやすいUI設計

### ② 複数条件検索

Ransackを利用し、地域、スープの濃さ、評価など  
複数条件を組み合わせて検索できるようにしました。

**技術的な工夫:**
- チェックボックスとセレクトボックスを組み合わせた直感的なUI
- 検索結果をリアルタイムで表示
- ページネーション（Kaminari）で見やすさを向上

### ③ コミュニティ機能

レビュー・評価・お気に入り登録を実装し、  
ユーザー同士で情報共有できるようにしました。

**技術的な工夫:**
- 星評価の平均値を自動計算
- CarrierWaveで写真付きレビューに対応
- お気に入り登録機能でユーザーの利便性を向上
